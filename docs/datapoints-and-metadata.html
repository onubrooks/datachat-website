DataPoints and Metadata

DataChat uses DataPoints as retrieval-ready context. Two common sources:

  • Managed: generated from profile + approved/synced.
  • User-trained: created from Train DataChat flow.

Metadata requirements

Generated and trained datapoints should keep these fields populated:

  • metadata.grain
  • metadata.exclusions
  • metadata.confidence_notes

Profiling signals used

Generation now leverages column profile details for richer grounding:

  • sample values
  • distinct counts
  • min/max where available
  • null counts where available

UI explorer behavior

  • Schema explorer and Metadata explorer are separate views.
  • Managed and approved records can be filtered.
  • Use details modal for full payload inspection and QA.

CLI helpers

uv run datachat dp pending list
uv run datachat dp list
uv run datachat dp sync --datapoints-dir ./datapoints
