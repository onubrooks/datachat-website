API and CLI

High-value CLI commands

uv run datachat dev
uv run datachat status
uv run datachat ask "list all available tables"
uv run datachat onboarding wizard --database-url postgresql://user:pass@host:5432/db
uv run datachat dp pending list
uv run datachat reset --yes

Core API endpoints (subset)

EndpointPurpose
POST /api/v1/chatAsk question and get answer + SQL artifacts.
GET /api/v1/system/statusRuntime readiness and initialization status.
POST /api/v1/datapoints/generateGenerate datapoints from profile.
GET /api/v1/datapoints/generate/jobs/{job_id}Poll generation job status.
POST /api/v1/datapoints/pending/{id}/approveApprove pending datapoint and sync.
POST /api/v1/system/resetReset runtime/system state for fresh tests.

Validation tips

  • Keep one known-good question set per domain and rerun after major changes.
  • Check SQL output first, then answer formatting and evidence.
  • When testing training flow, rerun the exact same question post-save.
