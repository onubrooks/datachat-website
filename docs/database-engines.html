Engine Support

AreaSupportedNotes
Target query enginePostgreSQL, MySQL, ClickHouseSupported in UI + CLI ask/onboarding flows.
System databasePostgreSQLUsed for connection registry, profiling jobs, pending approvals, and runtime state.
Metadata generationAll target engines aboveProfile data + generation path available; keep smoke tests green.

Recommendation

  • Use PostgreSQL for SYSTEM_DATABASE_URL.
  • Keep target DB separate from system DB in production-like setups.
  • Validate onboarding + ask + train + reset per engine before release.

Manual parity checklist

  1. Onboarding wizard completes.
  2. First ask returns SQL + answer.
  3. Train datapoint flow creates/updates and impacts retry.
  4. Reset clears runtime state and UI history.
