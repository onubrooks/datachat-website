Setup and Onboarding Flow

Default onboarding sequence:

  1. Connect target database.
  2. Generate metadata from profiling (recommended depth: metrics_full).
  3. Approve pending datapoints and sync.
  4. Ask first question.

Wizard-first path

uv run datachat onboarding wizard \
  --database-url postgresql://user:pass@host:5432/db \
  --depth metrics_full \
  --sample-size 120 \
  --batch-size 10

Settings-first path

  • Open /settings.
  • Set runtime config and secrets (provider, keys, target DB URL).
  • Save runtime config and secrets.
  • Return to chat and run onboarding.

Notes

  • If SYSTEM_DATABASE_URL is absent, registry/profiling/pending approval flows are limited.
  • If onboarding appears complete but chat still shows setup state, run reset once and rerun onboarding.
