Current Roadmap Focus

Near-term priorities are reliability and operational usefulness.

Now (active)

  • Onboarding reliability and setup guardrails.
  • Metadata generation quality and retrieval accuracy.
  • Train-from-answer stability and measurable improvement loops.
  • Reset/state hygiene and engine parity hardening.

Next

  • Document context layer v1 (local folders, PDFs, websites) with citations.
  • Guided workflow harness improvements (plan -> execute -> verify -> summarize).
  • Context/memory management improvements for long-running sessions.

Enterprise track

  • Remote enterprise connectors (Confluence, S3, Drive) with ACL-aware retrieval.
  • Metadata ops and semantic layer governance.
  • Policy-safe workflow execution and auditability depth.
