Troubleshooting

1) "DataChat requires a target database connection" after setup

  • Confirm target DB URL was saved in Settings or wizard.
  • Check GET /api/v1/system/status for readiness flags.
  • Run uv run datachat ask "list all available tables" from CLI to isolate UI issues.

2) Metadata generation keeps flickering/polling

  • Check generation status endpoint by job_id.
  • If job failed, inspect error and rerun from clean state.

3) Embedding/vector errors

  • Ensure LLM_OPENAI_API_KEY is set (required for current Chroma embedding path).
  • If Chroma storage gets locked/readonly, restart service and clear local vector artifacts.

4) Reset commands

# Full reset (recommended for fresh QA)
uv run datachat reset --yes

# Reset while keeping config
uv run datachat reset --keep-config --yes

# Reset including target DB clear
uv run datachat reset --include-target --yes

5) Bad SQL literals (example: positive vs up/down)

Recent updates add a context guard that remaps some categorical literals using profiled sample values. Re-profile + regenerate if schema/datapoints are stale.
