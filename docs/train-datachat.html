Train DataChat (Create/Update Query DataPoint)

Use this when an answer is weak or wrong and you want to teach DataChat an explicit SQL pattern.

Flow

  1. Run question in chat.
  2. Click Train DataChat.
  3. Choose create new or update existing training datapoint.
  4. Provide datapoint name, related tables, SQL, and metadata notes.
  5. Save, wait for sync/indexing confirmation, then ask again.

Recommended metadata notes

  • grain: e.g. daily_store_product
  • exclusions: e.g. returns, null statuses, archived records
  • confidence_notes: validation caveats and freshness assumptions

Example training payload guidance

Name: Weekly SKU Stockout Risk
Related tables: public.grocery_inventory_snapshots, public.grocery_products
Notes: Use latest available snapshot window (not CURRENT_DATE). Rank by available_qty - reorder_level.

What this improves

  • Retrieval ranking for similar questions.
  • SQL generation consistency on repeated intent.
  • Operator trust by exposing explicit query logic.
