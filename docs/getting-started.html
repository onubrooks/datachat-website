Getting Started in 5 Minutes

Minimum path for a first useful answer:

  1. Install and start app.
  2. Set provider key(s) and target DB in Settings or wizard.
  3. Run onboarding wizard (recommended).
  4. Ask first question and inspect SQL.

Install

git clone https://github.com/onubrooks/datachat-community.git
cd datachat-community
python3 -m venv venv
source venv/bin/activate
pip install -e .
uv run datachat dev

Required keys

  • LLM_OPENAI_API_KEY: currently required for Chroma embeddings.
  • Main chat provider keys: set based on selected provider (OpenAI/Google/Anthropic).

Database requirements

  • Target DB: PostgreSQL, MySQL, or ClickHouse.
  • System DB (optional but recommended): PostgreSQL for registry/profiling/pending approvals.

First question

uv run datachat ask "list all available tables"

If onboarding is complete and this still fails, use Troubleshooting.
