Open Source SQL-First

Ask business questions, inspect SQL, and improve answers with metadata.

DataChat is an AI data assistant focused on reliability over hype. You can connect a real database, generate and review metadata, run queries from chat or CLI, and teach the system using explicit datapoints.

Read Quickstart Browse Docs

Fast onboarding

Wizard-first flow: connect target DB -> generate metadata -> ask first question. Settings page can also be used for runtime keys and URLs.

Transparent answers

UI exposes answer, SQL, table, visualization, evidence, and timing. Multi-question responses can show subquestion-specific SQL and artifacts.

Teach the system

Use Train DataChat to create or update query datapoints from failed/weak answers, then retry and validate improvements.

Current capability snapshot

Target engines
PostgreSQL, MySQL, ClickHouse
System DB
PostgreSQL (recommended for registry, profiling, pending approvals)
Primary interfaces
Web UI + CLI
Metadata flow
Profile -> Generate -> Approve -> Sync -> Retrieve at query time
Embedding dependency
OpenAI key currently required for Chroma embeddings

Quick CLI example

# 1) Start services
uv run datachat dev

# 2) Optional full onboarding flow
uv run datachat onboarding wizard \
  --database-url postgresql://user:pass@host:5432/db \
  --depth metrics_full

# 3) Ask a question
uv run datachat ask "list all available tables"
