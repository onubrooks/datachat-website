AI data assistant built for operational reliability

Ask business questions, inspect SQL, and teach the system when answers are weak.

DataChat is a SQL-first assistant for teams that need useful answers, traceable logic, and controllable behavior. It combines chat + CLI, metadata generation, and explicit training loops without pretending to be a black-box autopilot.

Quickstart Explore features

Why teams use DataChat

Transparent outputs

Each response can expose answer, SQL, table, visualization, evidence, and timing so users can validate quickly.

Metadata-driven quality

Profile schema, generate managed datapoints, approve/sync, and retrieve better context at question time.

Train-from-answer loop

Turn weak answers into query datapoints and improve repeated intents without retraining a model.

What works today

Onboarding wizard

Connect DB -> generate metadata -> ask first question in one guided flow.

Engine support

Target DBs: PostgreSQL, MySQL, ClickHouse. System DB: PostgreSQL.

Settings-first runtime config

Provider keys and runtime settings can be managed in-product, not only via .env.

Schema + metadata explorer

Review table structure and generated/managed datapoints from the chat workspace.

CLI parity

Ask, onboarding, generate/approve datapoints, and reset flows are available via CLI for QA and automation.

Reset hygiene

Reset commands clear runtime state for repeatable test runs and launch smoke checks.

How the workflow looks

  1. Connect: add target database and provider keys.
  2. Ground: run profiling + metadata generation, approve candidates.
  3. Ask: inspect SQL and artifacts, not just plain answers.
  4. Improve: use Train DataChat for high-value failed intents.
