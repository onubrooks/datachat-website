Feature set focused on practical adoption

Core features that ship with real workflows, not just demos.

DataChat is optimized for teams that need logic visibility, metadata grounding, and repeatable QA paths across UI and CLI.

Wizard-first onboarding

  • Connect target DB directly in flow
  • Generate metadata with progress tracking
  • Advance to first question without config guesswork

Inspectable answer surface

  • Answer + query artifacts (including SQL) + table + visualization + evidence + timing
  • Multi-question handling with subquestion artifacts
  • Share, copy, and export actions

Metadata generation + review

  • Profile-derived sample values and distinct counts
  • Pending approval flow for generated datapoints
  • Schema and metadata explorer in chat workspace

Train DataChat loop

  • Create/update training datapoints from weak answers
  • Attach related tables and explicit SQL
  • Retry and verify behavior change

Engine coverage

  • Target queries: PostgreSQL, MySQL, ClickHouse
  • System state: PostgreSQL
  • Smoke tests across engine matrix in CI

Operational controls

  • Settings-first runtime configuration
  • Reset commands for clean QA runs
  • Community/private scope split documented

Example operator flow

# Ask a question
uv run datachat ask "Which 5 SKUs have the highest stockout risk this week?"

# If weak answer, teach query explicitly
# (UI: Train DataChat button)

# Re-ask and validate SQL + evidence
uv run datachat ask "Which 5 SKUs have the highest stockout risk this week?"
